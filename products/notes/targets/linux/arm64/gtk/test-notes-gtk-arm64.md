# `products/notes/targets/linux/arm64/gtk/test-notes-gtk-arm64`

A **1081-byte** statically-linked Linux ELF64 x86_64 structural verifier for
[`notes-gtk-arm64`](notes-gtk-arm64.md). Twelve `pread64` comparisons against
embedded expected bytes; exit `0` if all match.

The expected blobs and this verifier binary are machine code / literal bytes —
not generated by a committed script.
